HOW TO READ THE FIELD

Position

Right ascension and declination identify the centre of the solved image in celestial coordinates.

Field & scale

Width and height come from the provider's calibrated image dimensions. Pixel scale is arcseconds per pixel; field radius is kept separate.

Evidence over time

A capture date records when metadata was retrieved, not when the photo was taken. The real reference job is from the provider's API documentation.
